# 经营分析样例

panel 每行对应 zone_id 的一周，effective_area 单位平方米，rentable_days 为本周实际开放天数，occupied_area_days 为实际出租面积日，revenue 为元。fair_known_at 表示展会资料可用日，known_at 表示成交周资料可用日。topology 记录区块拆合，area_share 为面积份额，scenarios 的倍率作用于对应起报方案。

日期采用 ISO 8601；样例完全由固定种子生成，不含真实个人、机构或设备资料。字段缺省与数值零的含义不同。原有 fixtures/demo.json 仍用于既有业务流程。
